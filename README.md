# Maison Michèle Yakice E-Boutique

Je veux créer un site e-commerce premium, moderne, élégant et entièrement fonctionnel pour une maison de mode appelée Maison Michèle Yakice, spécialisée dans les vêtements de luxe en pagne tissé, lin et batik pour femme et homme.

IMPORTANT : Je ne veux pas un simple site vitrine. Je veux une véritable plateforme e-commerce professionnelle, pensée pour transformer la présence actuelle de Maison Michèle Yakice sur Facebook, Instagram, WhatsApp et les autres réseaux sociaux en un véritable système de vente digital.

L'objectif est de permettre aux clients de découvrir les collections, rechercher un vêtement, consulter les détails, choisir leur taille, ajouter au panier, passer commande, choisir la livraison et, lorsque le système de paiement est configuré, payer en ligne. Les clients doivent également pouvoir commander directement via WhatsApp.

L'administrateur doit pouvoir gérer les produits, les catégories, les tailles, les stocks, les commandes, les clients, les promotions et les livraisons depuis un véritable dashboard d'administration.
